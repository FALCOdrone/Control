This folder contains Model Predictive Control for quadcopter simulation in Copellia Sim.

To run:
-Install copellia sim 
-Install required python libraries 
-Open drone_scene.ttt  
-Run the MPCv4.x.py script

versions: Best version kept at v4.0.0

Scripts:
- plot_trajectory_xy.py  --> Plots the drone's an the target's trajectory from a top down view.
- plot_trajectory_xyz.py --> Plots the drone's an the target's trajectory from a 3D view.
- plotting.py            --> Plots the states of the drone and some additional variables.
